## 認知成本制衡

一句話：抽象思考能帶來洞察，但若進入遞迴過深，會消耗行動力；需要用身體需求與簡單行動作為停止規則。

結構：

```text
abstraction → insight
over-abstraction → meta-loop / paralysis
body need / simple action → negative feedback → return to function
```

使用句：

```text
這個模型先暫停，我現在只執行身體需求。
```

詞庫賣點：不只是收集抽象結構，也保存「何時停止抽象」的制衡機制，避免模型吞掉行動。

例子：

- 思考政治模型太久 → 先吃飯
- 哲學反思陷入循環 → 先睡覺/散步
- 工程設計過度抽象 → 先做最小可行版本
- 投資分析無限展開 → 先定義決策條件

相近概念：bounded rationality, grounding, action bias, somatic marker, anti-rumination, satisficing
