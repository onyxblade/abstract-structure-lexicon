## 事實符合性—事實不可達性

一句話：任何說法都可以被分析其是否符合事實；但我們接觸到的永遠是證據、觀察、模型與語言，而不是事實本身的原貌。

結構：

```text
statement
→ claim about fact
→ compare with evidence / observation / model
→ judge: more or less fact-conforming
```

底層限制：

```text
fact-in-itself
→ inaccessible directly
→ mediated by perception / instrument / language / model / social process
→ fallible judgment
```

核心修正：

```text
無法知道事實本身 ≠ 所有說法一樣真
無法直接接觸事實本身 → 只能比較說法與可得證據的符合度
```

認識論位置：

```text
naïve realism：以為自己直接掌握事實本身
total relativism：因為無法直接掌握事實，就否定真假差異
fallibilist realism：有事實約束我們，但我們只能透過可錯中介逼近它
```

程序 / AI 版本：

```text
input claim
→ retrieve evidence
→ check consistency
→ assign confidence
→ keep possibility of revision
```

核心判準：

```text
不是問：我是否擁有事實本身？
而是問：
在目前可得中介下，哪個說法更受約束、更少矛盾、更能預測與解釋？
```

例子：

- 科學：理論不是事實本身，而是被實驗與觀察約束、可修正的模型
- 新聞：報導不能直接等於事件本身，只能比對來源、證據、時間線與一致性
- 法律：法院無法回到事件本身，只能用證據程序重建較可信版本
- AI：模型不能直接接觸世界，只能處理文件、資料、工具輸出與推理一致性
- 個人記憶：回憶不是過去本身，而是由當前狀態重新建構的證據片段

相近概念：fallibilism, realism, correspondence theory, mediated realism, evidence, model, uncertainty, epistemology, truth-seeking
