## 部分結構現實

一句話：現實中的關係常是部分定義的，但模型為了簡潔會把它們寫成全定義結構；錯誤常出現在起源、邊界、缺失與例外處。

結構：

```text
common case relation
→ modeled as total function
→ boundary / origin / missing case appears
→ contradiction / fiction / forced closure
→ revise to partial function / nullable relation / open boundary
```

數學版本：

```text
錯誤建模：f: A → B
較貼近現實：f: A ⇀ B
```

核心洞察：

```text
usually has X
→ modeled as must have X
→ edge case breaks model
```

典型失敗：

```text
total model
→ every element must have a value
→ origin / boundary has no natural value
→ self-loop / infinite regress / artificial exception
```

例子：

- 家譜：若 `father: Humans → Humans`，最初的人類可能被迫有自己作為 father，或出現循環/無限回溯；較合理是 `Humans ⇀ Humans`
- 程式：假設每個 key 都有 value；現實有 missing / null / undefined
- 資料庫：假設每筆 record 都有完整 foreign key；現實有 nullable FK、外部資料、orphan row、資料缺失
- 哲學：假設每個事件都有清楚單一原因；現實有起源問題、邊界問題、複數因果
- 語言：假設每個詞都有固定定義；現實有家族相似、模糊邊界、語境依賴
- 身分：假設每人都有穩定類別；現實有轉換、混合、未定義、自我描述變動

相近概念：partial function, total function, nullable relation, edge case, boundary condition, origin problem, model mismatch, open-world assumption
