## 信號壓制—可恢復盲點

一句話：系統可能不是缺少相關資訊或能力，而是某些高權重信號主導當前處理路徑，壓低其他本可使用的信號；重新提示可使盲點恢復可見。

結構：

```text
multiple available signals
→ salience / attention / instruction weighting
→ dominant signal rises
→ competing signals are suppressed
→ narrow output / temporary blind spot
```

恢復結構：

```text
prompt mentions suppressed dimension
→ its weight rises
→ context is reorganized
→ alternative relation becomes generatable
→ blind spot becomes visible
```

三層區分：

```text
knowledge / signals available
≠ knowledge / signals activated
≠ knowledge / signals expressed
```

兩種不知道：

```text
缺失型不知道：
資訊或能力不存在
→ 提示未必能恢復

壓制型不知道：
資訊或能力存在，但未進入當前路徑
→ 適當提示可能恢復
```

與偏向—盲點的關係：

```text
signal A 升權
→ processing biased toward A
→ signal B 被相對壓低
→ B 成為暫時盲點

prompt raises B
→ alternative activation
→ recoverable blind spot exposed
```

常見增權因子：

```text
近期性 / recency
重複 / repetition
位置 / placement
語氣與情緒強度
指令優先級
與當前生成路徑的一致性
既有框架與預期
```

盲點掃描：

```text
single prompt
→ dominant path

prompt perturbation
→ alternative activations
→ compare outputs
→ expose recoverable blind spots
```

例子：

- LLM：上下文中的近期或強烈信號壓過較早線索；明確提示後又能正確使用該線索
- 討論：一個情緒強烈的案例壓過基準率；提醒統計背景後判斷改變
- 除錯：先入為主的原因假設使其他證據被忽略；換人提問後看到另一條路徑
- 組織：主管的框架主導會議，使基層資訊雖已存在卻無法進入決策
- 個人認知：焦慮信號升權，使安全或正面訊號暫時不可見

相近概念：bias, blind spot, signal competition, attention, salience, context weighting, retrieval failure, prompt sensitivity, inhibition, recency bias
