## 客觀作為共享不變項

一句話：客觀不是直接取得物自身，而是在多個解讀器之間比較後，抽取出不隨觀點變化而消失的共同不變項。

結構：

```text
thing / event / signal
→ interpreted by subject A
→ interpreted by subject B
→ compare interpretations
→ shared invariant
→ objective-for-A-and-B
```

分類：

```text
A-only：只在 A 的解讀中成立
B-only：只在 B 的解讀中成立
A∩B：兩者共有，較客觀
A∪B：兩者合併後的完整可談論空間
Neither：兩者都沒捕捉到，但可能存在
```

多觀點版本：

```text
perspective = interpreter
objectivity = invariant across interpreters
classification = partition by interpreter-dependence
```

客觀層級：

```text
個體主觀：只在一個解讀器內成立
局部客觀：少數解讀器共享
群體客觀：大量人共享
儀器客觀：人與儀器/程序都能穩定重現
跨框架客觀：不同理論、文化、方法仍收斂
極限客觀：理想上所有足夠好的解讀器都會收斂
```

核心修正：

```text
客觀 ≠ 多數同意
客觀 = 在不同解讀方式變化下仍保持穩定的部分
```

數學類比：

```text
perspective changes
but some structure remains
→ invariant under transformation
```

核心張力：

```text
沒有共享不變項 → 只剩私人經驗 / 無法共同分類
把共享不變項絕對化 → 誤以為已直接掌握物自身
```

例子：

- 視覺：不同角度看杯子，形狀投影改變，但可抽取同一物體的穩定結構
- 科學：不同儀器、實驗室、研究者得到可重現結果，客觀性上升
- 社會：不同政治立場都承認某事件發生，但對意義與責任解讀不同
- 程式：不同 client 對 API 有不同使用情境，但共同 schema 是共享不變項
- 語言：不同語境下詞義有變化，但仍有足夠重疊使溝通可能

相近概念：objectivity, invariant, intersubjectivity, perspective, interpreter, triangulation, reproducibility, shared reality, structural realism
