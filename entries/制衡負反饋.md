## 制衡負反饋

一句話：當某種力量有自我擴張傾向時，需要一個負反饋機制把它拉回可控範圍。

結構：

```text
power → self-expansion → concentration risk
counter-force / feedback → correction → bounded power
```

民主視角：

```text
權力擴張 → 選舉 / 輿論 / 分權 / 法治 / 抗議 → 修正或替換掌權者
```

核心張力：

```text
負反饋太弱 → 權力失控 / 專制化
負反饋太強 → 決策癱瘓 / 短期民粹
適中 → 權力可用但受限
```

例子：

- 民主制度對抗權力集中
- 市場競爭限制壟斷企業
- 免疫系統抑制異常細胞增殖
- peer review 抑制學術權威壟斷
- code review 抑制個人錯誤進入系統

相近概念：negative feedback, checks and balances, separation of powers, cybernetics, anti-monopoly, homeostasis
