## 槓桿化價值捕獲

一句話：商業的本質不是單純交換，而是把有限資源接上槓桿，使一次投入能產生超過個人直接勞動的回報，並捕獲其中剩餘。

結構：

```text
resource / insight / labor / capital
→ leverage mechanism
→ amplified reach / output / return
→ surplus capture
```

商業流程：

```text
找到槓桿
→ 控制槓桿
→ 捕獲槓桿產生的剩餘
→ 承擔或轉嫁槓桿放大的風險
```

核心判準：

```text
這件事能不能在不線性增加本人勞動的情況下擴大？
不能 → 工作 / 手藝 / 服務
能 → 商業 / 系統 / 資產
```

常見槓桿：

```text
capital → 用錢調動資源
labor → 用組織調動多人時間
technology → 用工具降低邊際成本
media → 一次創作，多次分發
brand → 壓縮信任成本
distribution → 接近需求、控制渠道
network effect → 用戶增加讓產品更有價值
law / IP → 用制度保護可重複收租的位置
process → 把個人能力封裝成可複製系統
```

核心張力：

```text
槓桿 ↑ → 規模、利潤、影響力 ↑
槓桿 ↑ → 失真、風險、外部性、控制問題 ↑
```

例子：

- 軟體：一次開發，近零邊際成本分發給大量用戶
- 品牌：讓陌生人更快信任，降低每次交易的說服成本
- 平台：把供需雙方接到同一結構中，從網路效應抽取價值
- 內容：文章、影片、課程一次製作，多次出售或分發
- 金融：用資本槓桿放大收益，同時放大損失
- 組織：把個人能力轉成流程、職位、管理結構與可替換執行

相近概念：leverage, scalability, value capture, surplus, capital, media leverage, network effect, marginal cost, compounding, rent
