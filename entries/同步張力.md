## 同步張力

一句話：個體會被環境塑造成與環境同步；但同步需要決定「過去經驗」和「當前訊號」誰的權重更高。

結構：

```text
environment → adaptation → fit / sync → advantage
environment changes → old adaptation mismatch → disadvantage
```

核心張力：

```text
past-weight ↑ → 穩定、保守、抗噪音，但可能過時
present-weight ↑ → 靈活、更新快，但可能被短期噪音帶偏
```

簡化模型：

```text
behavior = past_experience × memory_weight + current_signal × update_weight
```

例子：

- 動物：過去被捕獵 → 怕人；若環境變安全，過度怕人反而成本高
- 人：童年環境塑造防衛模式；成年環境改變後，舊模式可能不合時宜
- 投資者：熊市記憶讓人保守；牛市環境下可能錯失機會
- 組織：舊危機形成流程；環境變快後流程可能變成負擔

相近概念：adaptation, path dependence, Bayesian updating, hysteresis, overfitting to the past, ecological rationality
