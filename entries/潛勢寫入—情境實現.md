## 潛勢寫入—情境實現

一句話：訓練不是立刻產生行為，而是把某種信息、傾向或能力寫入個體，使它在未來情境中被 actualize。

結構：

```text
input / repetition / feedback
→ internalization
→ latent disposition / parameter change
→ future context
→ actualized behavior
```

模型版本：

```text
training data + loss feedback
→ parameter update
→ latent capability / bias
→ prompt / context
→ output
```

人類版本：

```text
experience + repetition + reward/punishment
→ memory / skill / habit / emotional marker
→ situational trigger
→ behavior / judgment / reaction
```

核心張力：

```text
訓練寫入的是未來可能性，不是未來行為本身
actualization 會被當前情境、既有結構、其他訓練痕跡、目標/壓力、觸發方式重新組合
```

例子：

- LLM：訓練語料留下能力與偏向；prompt 決定哪些潛勢被喚出
- 人類技能：練習鋼琴/程式後，能力在具體曲子或問題中展開
- 習慣養成：重複行為被寫入身體，之後由場景觸發
- 創傷/風險記憶：危險經驗被內化，未來相似情境中變成防衛反應
- 教育：知識未必立即使用，但會改變之後理解世界與解題的方式

相近概念：training, internalization, latent disposition, actualization, habit formation, generalization, overfitting, bias, prompt dependence
