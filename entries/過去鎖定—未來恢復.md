## 過去鎖定—未來恢復

一句話：抑鬱式思維常把注意力鎖在不可改寫的過去；康復則是把過去轉化為資料，重新恢復對未來的行動感。

結構：

```text
past event
→ rumination / regret / shame
→ sense of irreversible loss
→ lowered agency
→ less future action
→ more evidence that "nothing changes"
→ deeper past-lock
```

恢復結構：

```text
過去事件
→ 承認損失
→ 提取資訊
→ 降低自我審判
→ 小型未來行動
→ agency 回升
→ 未來重新開放
```

核心判準：

```text
回顧是否產生新的可行動差異？
有 → 學習 / 整合
無 → 反芻 / 過去鎖定
```

核心張力：

```text
面向過去不是問題；
問題是過去是否從「資料」升格成「審判者」。

康復不是否定過去；
而是把過去降級為資料，讓未來重新成為可操作空間。
```

例子：

- 心理：反覆重播失敗或羞恥經驗，卻沒有新資訊或行動出口
- 創傷：過去危險持續支配現在，使安全情境也被解讀成威脅
- 職涯：被一次失敗定義自我，停止嘗試新的可能
- 關係：過去傷害變成對所有未來關係的預設判決
- 組織：舊事故讓制度永遠保守，無法根據新環境更新

相近概念：rumination, depression, learned helplessness, agency, future orientation, trauma integration, cognitive reframing, behavioral activation
