## 描述—規範迴路

一句話：對現實的描述，一旦被權威化，就會反過來規範現實。

結構：

```text
practice → description → codification → authority → norm → changed practice
```

例子：

- 詞典：描述用法 → 變成正確用法標準
- KPI：衡量工作 → 反過來塑造工作
- DSM：整理症狀 → 決定什麼算疾病
- 排行榜：描述排名 → 變成人們追逐的目標

相近概念：performativity, feedback loop, reification, Goodhart’s law, social construction
