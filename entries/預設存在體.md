## 預設存在體

一句話：object 不是已證明存在的東西，而是系統暫時假定其存在，並圍繞它建立引用、屬性、操作與推理。

結構：

```text
signal / name / reference
→ presumed existence
→ attach properties
→ allow operations / reasoning
→ failure if presumption breaks
```

哲學版本：

```text
world / experience
→ carve out something as "object"
→ presume continuity / identity / separability
→ reason about it as if it exists
```

程序版本：

```text
object reference
→ presumed allocated entity
→ fields / methods / identity
→ operations
```

核心張力：

```text
沒有 object → 無法操作、推理、壓縮世界
過早 object 化 → reification / false entity / null reference
```

失敗模式：

```text
presumed existence failed
→ null / undefined / missing reference
→ dangling reference
→ stale cache / deleted row
→ API schema mismatch
→ false entity / reification
```

例子：

- 哲學：「桌子」把感覺、功能、邊界穩定化成一個可談論 object
- 自我：「我」被預設有連續性，才能承擔記憶、責任與計畫
- 社會：「國家」「市場」「疾病」是制度與語言維持的高階 presumed existence
- 程式：`user.name` 預設 `user` 是存在且有結構的 object
- 資料庫：程式假定某筆 row 存在；若已刪除或未建立，操作失敗
- API：client 假定回傳 JSON 有某欄位；schema 改變時 presumption 破裂

相近概念：object, reference, ontology, reification, entity, identity, null pointer, dangling reference, abstraction, constructivism
