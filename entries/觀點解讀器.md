## 觀點解讀器

一句話：觀點不是單純意見，而是一套把事物轉換成意義、判斷與行動傾向的解讀方式；觀點也可依其傳播能力被分析。

結構：

```text
thing / event / signal
→ perspective / interpretive frame
→ meaning
→ evaluation
→ action tendency
```

同物異解：

```text
same object
+ different interpreter
→ different world
```

傳播結構：

```text
interpretive frame
→ transmissibility
→ adoption
→ reproduction
→ social reality shaping
```

傳播參數：

```text
簡潔性：能不能一句話講清楚？
情緒張力：會不會激發憤怒、希望、恐懼、優越感？
解釋力：能不能把很多現象統一起來？
身分綁定：接受它是否等於成為某種人？
行動指令：它是否告訴人接下來該做什麼？
反駁免疫：它是否能吸收反例？
社交收益：傳播它是否帶來地位、歸屬或道德優勢？
制度適配：是否能被學校、媒體、公司、國家採用？
```

核心張力：

```text
高傳播性 ≠ 高真實性
高真實性 ≠ 高傳播性

傳得快的觀點：簡單、情緒強、身份化、可重複
較準的觀點：細緻、條件化、可修正、但較難傳播
```

層級：

```text
perspective = interpreter
meme = transmissible interpreter
ideology = socially stabilized interpreter
institution = embodied interpreter
```

例子：

- 政治：同一事件可被解讀成壓迫、秩序、改革、陰謀或利益衝突
- 科學：同一數據在不同理論框架中有不同意義
- 品牌：同一產品被解讀成身份、效率、審美或社群歸屬
- 心理：同一句話可被解讀成批評、提醒、關心或威脅
- 組織：同一錯誤可被解讀成個人責任、流程缺陷或資源不足

相近概念：perspective, interpretive frame, meme, ideology, framing, schema, hermeneutics, transmissibility, social construction
